# 📦 Product API - Node.js (Express)

Projeto desenvolvido para estudo prático de backend com Node.js e Express.

O objetivo foi entender na prática como construir uma API REST do zero, aplicando arquitetura limpa, separação de responsabilidades e lógica de CRUD 

---

# 🚀 Sobre o projeto

Esta API simula um sistema de gerenciamento de produtos, permitindo:

- Criar produtos
- Listar produtos
- Buscar produto por ID
- Atualizar produto
- Deletar produto

com dados salvos em banco de dados (postgree)

---

# 🧠 O que foi aprendido

Durante o desenvolvimento, foram estudados e aplicados os seguintes conceitos:

## 🔹 Express.js
- Criação de servidor
- Rotas HTTP (GET, POST, PUT, DELETE)

## 🔹 Arquitetura de backend
- Separação em:
  - Routes
  - Controllers
  - Services

## 🔹 CRUD
- Create
- Read
- Update
- Delete

## 🔹 JavaScript avançado
- Arrays
- find()
- findIndex()
- filter()
- spread operator (...data)

## 🔹 Middlewares
- Logger de requisições
- Validação de dados no POST

## 🔹 Tratamento de erros
- Criação de erro customizado (AppError)
- Uso de throw para regras de negócio
